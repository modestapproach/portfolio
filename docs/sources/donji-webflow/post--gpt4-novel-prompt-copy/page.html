How to write a Novel with ChatGPT 4 Copy

So I've been working on a prompt for generating novels with ChatGPT, and so far, its been a pretty enjoyable process.

This technique uses 3 prompts
1st - Sets up the chapters
2nd - Tells the story of the first chapter
3rd - Tells the story of all the other chapters

I linked the prompts in a github gist, and included the gpt-3 and gpt-4 model versions of the stories so you can compare and contrast the outputs.

  • Link to the 3 prompts: https://gist.github.com/DonjiKong/b98bcc47c76e1c983acd8e0032693987
  • Gpt-3 story: https://gist.github.com/DonjiKong/54cb23c9a80a9681f9d575109c458578
  • Gpt-4 story: https://gist.github.com/DonjiKong/d0536811d19262399a4ab865a482a31c
  • Youtube video going over how the prompt works in more depth: https://youtu.be/gTphyWyNVMI

I'm curious on how all of you would remix this prompt to create better results. Reach out to me on twitter or in the youtube comments in the video.
