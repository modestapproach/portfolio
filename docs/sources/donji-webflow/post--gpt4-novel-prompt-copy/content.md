# How to write a Novel with ChatGPT 4 Copy

![Blog Single Image](https://cdn.prod.website-files.com/626ed9ada82a85619f6ab7f6/641259e9ebc2294d0650ac43_Youtube%20Template%202.jpg)

[video: https://www.youtube.com/watch?v=gTphyWyNVMI]

So I've been working on a prompt for generating novels with ChatGPT, and so far, its been a pretty enjoyable process.

This technique uses 3 prompts 1st - Sets up the chapters 2nd - Tells the story of the first chapter 3rd - Tells the story of all the other chapters

I linked the prompts in a github gist, and included the gpt-3 and gpt-4 model versions of the stories so you can compare and contrast the outputs.
