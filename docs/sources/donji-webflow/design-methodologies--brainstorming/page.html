Brainstorming

Project: Custom built brainstorming tool

Custom-made diagram whiteboard for brainstorming sessions (2015)

I noticed that many brainstorming sessions out in the wild just use post its, but post-its aren't great when you need to use a diagram. I printed out these diagrams, and I found out that kinko's actually has a custom whiteboard coating for posters.

Diagrams include:
- SWOT analysis
- Stakeholder mapping
- Touchpoint Diagram
- Customer Journey map
‍
These reusable whiteboard posters save a bunch on money and paper because writing on them doesn't mean you have to reprint them every time.

This was a great experiment and this method is great in very specific scenarios, but ultimately, tools like miro now are much more extensible and accessible. (I created these before anything like miro existed)

Project: Kickback

Virtual Venn Diagram Brianstorm using Miro

Expansive Solo/Individual Brainstorming

In this diagram, I set up a miro document with a venn diagram in it to categorize a list of potential features we came up with in a separate brainstorming session into different market segments.

Before I bought this to the team to categorize, I did about a third of the categorizing myself, then I ran a session where my team and I categorized the rest.

While I could have done it all myself, I think it's great to include the team on exercises like this so everyone starts thinking from the same base principles in mind.
